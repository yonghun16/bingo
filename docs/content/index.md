# 프로젝트 개요

최대 5명이 함께 즐기는 웹 기반 실시간 멀티플레이어 빙고 게임입니다. 로그인/인증 없이 닉네임만으로 참여하는 프로토타입이며, 별도 게임 서버 없이 Supabase Realtime으로 클라이언트끼리 이벤트를 중계합니다(데이터는 각 클라이언트 로컬 상태가 원본이며 DB에 영구 저장하지 않음, 새로고침 시 초기화).

게임 상태(참가자, 보드, 호출 숫자, 턴, 승패)의 원본 소스는 각 클라이언트이고, Supabase Realtime은 "숫자가 호출됐다" 같은 이벤트만 방 전체에 중계하는 역할만 한다. 자세한 원칙은 [[게임흐름]]의 "실시간 동기화 원칙" 참고.

| 영역 | 스택 | 배포 |
|---|---|---|
| 프론트엔드 | Vite + React + TypeScript + React Router + Tailwind | Oracle VM(nginx) 또는 Vercel |
| 실시간 인프라 | Supabase Realtime (Broadcast + Presence, 별도 서버 코드 없음) | Supabase 관리형 프로젝트 |

# 게임 방법

1. **방 만들기**: 방장이 방을 만들면 고유 room ID와 초대 링크가 생성된다.
2. **입장**: 다른 유저는 링크로 접속해 닉네임을 입력하고 입장한다. 정원은 최대 5명이며, 이미 게임이 시작된 방에는 입장할 수 없다.
3. **빙고판 세팅**: 좌(5x5 보드) / 우(실시간 채팅) 2분할 화면에서 1~25 숫자를 중복 없이 전부 배치하면 "준비 완료" 처리된다. 최소 2명 이상 전원이 준비를 마치면 자동으로 게임이 시작된다.
4. **게임 진행(턴제)**: 입장 순서대로 턴을 가지며, 현재 턴 유저는 10초 안에 아직 불리지 않은 숫자를 호출한다. 시간 초과 시 방장(호스트) 클라이언트가 남은 숫자 중 랜덤 자동 호출. 숫자가 호출되면 전원의 보드에서 해당 숫자가 자동 마킹된다.
5. **승리 조건**: 가로 5줄 + 세로 5줄 + 대각선 2줄, 총 12줄 중 3줄을 먼저 완성하면 우승. 동시 달성 시 공동 우승.
6. **게임 종료**: 우승 즉시 게임이 끝나고 전원의 보드가 공개되며, "다시 하기"로 같은 방에서 새 게임을 시작할 수 있다.
7. **채팅**: 화면 오른쪽에서 게임 시작 전/후 언제든 닉네임 + 메시지 + 타임스탬프 형식으로 채팅할 수 있다.

자세한 스펙은 [[게임흐름]] 문서를 참고한다.
